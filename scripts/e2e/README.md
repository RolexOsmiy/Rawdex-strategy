# E2E-проверка загрузки карты

Запускает игру в настоящем Chromium (Edge) без дисплея и проверяет весь путь:
загрузка карты → игровой экран → панель настроек → живое переключение
MSAA/масштаба рендера и проверка изображения карты без MSAA → счётчик FPS → старт партии и ход симуляции.

## Установка (один раз)

```bash
cd scripts/e2e
npm install        # только playwright-core (маленький пакет)
```

Браузер не скачивается — используется установленный Edge (путь можно переопределить
переменной `BALTRIC_EDGE`). Если Edge нет — поставьте Chrome и укажите путь к нему.

## Запуск

```bash
node run.cjs baltic          # Балтийская карта
node run.cjs mediterranean   # Средиземноморье
```

Возвращает код 0 при успехе, 1 при ошибке загрузки, 2 при сбое самого теста.
В выводе: время загрузки, состояние панели настроек, фактический sampleCount
видеокарты, размер холста, показания счётчика FPS, даты симуляции, ошибки
консоли браузера, видимость местности внутри контуров держав и совпадение контуров
с картой при перетаскивании, зуме и повороте,
а также проверка зума колесом (метки не исчезают при
движении камеры, нет дублей строк держав и подписи моря на обзоре).
Отдельно проверяются позиция строительных меток, список выбранных войск
и общий маршрут двух отрядов после клика вне дороги. Тест также декодирует
звуковые записи и проверяет запуск звука при выборе постройки.
Повторные приказы проверяются внутри одного тика. Для круговых индикаторов
проверяются три разных лидера, цвета рамок и заполнение окружности.

## Бенчмарк FPS в Chromium

```bash
node bench.cjs baltic          # разные настройки рендера, DPR 1 и 1.25
```

Эти тесты ловят именно те поломки, что уже не раз ломали запуск игры
(смешанный кэш скриптов, ошибки инициализации UI). Запускайте их после
правок `dist/`, `gpu/` и локализации.
