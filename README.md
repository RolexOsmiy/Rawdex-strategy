# Балтийские пути

Браузерная стратегия в реальном времени с двумя кампаниями, 3D-картой на WebGPU и одиночной игрой против ботов.

## Настольная сборка Windows

Игра запускается в Tauri 2 с Microsoft Edge WebView2. Релиз включает все файлы игры и открывается без локального HTTP-сервера. Для карты требуется WebGPU с аппаратным ускорением.

Для сборки установите Node.js, стабильный Rust с целью `x86_64-pc-windows-msvc` и Visual Studio Build Tools с компонентами MSVC и Windows SDK. [Требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/#windows).

Для чистой сборки запустите `build-windows.bat` в корне проекта. Он установит Node-зависимости по `package-lock.json`, соберёт Rust в отдельной временной папке и положит исполняемый файл и установщик NSIS в `builds/`. Для запуска из терминала без ожидания нажатия клавиши используйте `.\build-windows.bat --no-pause`.

Для разработки из корня проекта выполните:

```powershell
npm ci
npm start       # окно разработки
```

По умолчанию игра открывается на весь экран. **F11** переключает режим окна. Шестерёнка на карте открывает настройки масштаба рендера, сглаживания и счётчика FPS.

Настройки сохраняются в `%APPDATA%\com.rawdex.balticroads\settings.json`. При первом запуске Tauri подхватывает полноэкранный режим и настройки графики из прежней настольной сборки, если её файл настроек есть.

## Запуск в браузере

Откройте терминал в корне проекта. В Windows запустите:

```powershell
py -3 -m http.server 8000 --directory dist
```

В Linux или macOS запустите:

```bash
python3 -m http.server 8000 --directory dist
```

Затем откройте [http://localhost:8000/](http://localhost:8000/). Для отрисовки карты нужен браузер с WebGPU и включённым аппаратным ускорением.

Для размещения на хостинге скопируйте содержимое `dist/` в папку сайта, доступную по HTTPS. Веб-сервер отдаёт статические файлы игры из этой папки. Сборка и установка JavaScript-зависимостей для запуска не требуются.

## Структура

- `dist/` — готовая к запуску игра, карты, локализация и графический движок.
- `build-windows.bat` — чистая сборка Windows x64.
- `src-tauri/` — настольная оболочка Windows и конфигурация установщика.
- `docs/` — документация проекта и сведения о [языках интерфейса](docs/localization.md).
- `scripts/` — инструменты для работы с данными проекта.
