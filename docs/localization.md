# Языки игры

Обе кампании используют общий каталог. В главном меню доступны русский, английский, немецкий, французский, испанский, бразильский португальский, польский, турецкий, упрощённый китайский, японский, корейский и украинский. Выбор сохраняется в браузере. Ссылкам на конкретную кампанию можно передать язык, например `?map=mediterranean&lang=ja`.

Каталог охватывает меню, карты, игровые панели, подсказки, уведомления, приказы, условия победы и итог кампании. Тексты хранятся локально и загружаются вместе с игрой. Русский остаётся исходным языком. Для расширения каталога использовались локальные модели Argos Translate и OPUS-MT, а названия и отдельные игровые формулировки сверялись вручную.

## Добавление текста

Каталог находится в `dist/locales/catalog.js`. Каждая строка начинается с русской фразы. Остальные столбцы следуют порядку языков в `dist/locales/interface.js` и разделяются знаком `|`.

Новое сообщение с числом или названием оформляйте одной строкой с параметрами `{0}`, `{1}` и передавайте значения в `gameI18n.text`. Это позволяет переводчику поменять порядок слов. Для дат используйте `gameI18n.date`, для заголовка с месяцем и годом — `gameI18n.month`. Идентификаторы герцогств, держав, поручений и событий сохраняйте в исходном виде.

Запустите `node verify-localization.cjs` из корня проекта, чтобы проверить язык, сообщения и порядок параметров. Параметр `locale-debug=1` открывает список строк, для которых отрисовка не нашла полного совпадения, через `gameI18n.missing()`.
